# nlmixr2utils

Shared infrastructure for the `nlmixr2` extension packages `nlmixr2boot`,
`nlmixr2llp`, `nlmixr2scm` and `nlmixr2sir`. Based in large part from 
pre-existing code in `nlmixr2extra`, developed by Matt Fidler, Vipul Mann,
Vishal Sarsani, Christian Bartels and Bill Denney. 

## Installation

Install the released version from CRAN:

``` r
install.packages("nlmixr2utils")
```

Or install the development version from GitHub:

``` r
# install.packages("pak")
pak::pak("nlmixr2/nlmixr2utils")
```
